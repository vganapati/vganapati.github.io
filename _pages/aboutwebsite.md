# Use this website as a template for your academic research group

This website is powered by [Jekyll](https://jekyllrb.com) and uses some [Bootstrap](http://www.getbootstrap.com) and  [Bootswatch](http://www.bootswatch.com). The original code is forked from [Allan Lab @ Leiden University](https://github.com/allanlab/allanlab). See their [website](https://www.allanlab.org/aboutwebsite.html) for more information on how to use and modify their code for your own research group site.
